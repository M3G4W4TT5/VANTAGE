# Vantage final logo assets

Ten PNG assets derived directly from the approved clean logo.
The wide V and triangle geometry are preserved. No glow.

Transparent files use real alpha transparency; opaque versions use pure black or white backgrounds.
Each group uses identical dimensions and a 32 px clear margin. Assets retain their native raster scale.
